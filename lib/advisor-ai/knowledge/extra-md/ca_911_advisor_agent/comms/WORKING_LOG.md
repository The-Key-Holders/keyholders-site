# Working log entry template

Draft for Advisor Desk after each material contact.

```text
Date:
PSAP / County / Code:
Contact name / role:
Channel: phone | email | meeting | other
Topic tags: [CPE|Residual|FOR|Claim|NG|Network|NewPSAP|Transition|Other]
Summary (3–6 bullets):
Commitments made:
NEXT ACTION / owner / due:
Documents referenced:
Follow-up email drafted: Y/N (template id)
Escalate to: none | supervisor | fiscal | network | other
```

## Close checklist (from Top-15 aid)

1. Restate next action  
2. Note PSAP code, date, commitment  
3. Send follow-up with form links
