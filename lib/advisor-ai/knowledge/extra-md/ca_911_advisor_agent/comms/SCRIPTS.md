# Live call scripts

## Unknown-issue opener (30–60s)

1. Confirm PSAP and caller role  
2. One-sentence problem  
3. Route: CPE / network / residual / performance / other  
4. Mentally open decision tree Aid 01  
5. Capture commitment + log  

## Low answer-time

1. Partnership framing  
2. State standard (90% in 15s)  
3. Share observed window from real ECaTS  
4. Ask what they already see  
5. Agree 1–2 follow-ups  
6. Offer written summary email  

## Residual clock warning

1. Confirm acceptance date  
2. State residual $ only if known from package  
3. List rule + workspace rule  
4. Quote ~90 days / invoice ~12 months  
5. Offer item pre-check  

## Estimate disclaimer (verbal)

“I can walk an estimate from ECaTS using the fixed allotment calculator. The official amount is only the Branch allotment letter after Advance Notification.”
