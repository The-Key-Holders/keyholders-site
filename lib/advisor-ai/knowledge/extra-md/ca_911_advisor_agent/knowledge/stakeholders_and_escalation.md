# Stakeholders and escalation

---

## Stakeholder map

| Stakeholder | Role relative to Advisor work |
|-------------|-------------------------------|
| PSAP Manager / admin | Customer for packages, acceptance, residual shopping |
| County Coordinator | MSAG/coordination; may claim approved time |
| CPE vendors (MPA/CMAS) | Quotes, SOW, install, direct invoices |
| Network providers | Network records, moves impacting CPE |
| CA 9-1-1 Branch Advisors | Human authority for packages and judgment |
| Fiscal / Reconciliation | ETS, payments, invoice naming |
| Lab validation / contracts | Who may sell funded call-handling systems |
| Wireless / CHP SMEs | Routing edge cases |
| Advisory Board | Policy advice; not day-to-day package ops |
| Language Line / interpretation vendor | FOR foreign language costs |

---

## Escalate to human when

| Situation | Why |
|-----------|-----|
| Official allotment letter / TD-288 issuance | Authority |
| Off-list residual insistence | Policy exception risk |
| Damage / negligence / early replacement | Case-by-case |
| Mid-stream MPA conversion without memo | Needs Branch-approved transition guidance |
| Invoice payment disputes | Fiscal |
| ETS BTN misassignment | Fiscal correction |
| Network design changes | Network SME |
| Novel policy not in Manual | Supervisor / leadership |
| Substandard answer times needing formal letter | Compliance process |
| Life safety emergency | **Call 9-1-1** |
