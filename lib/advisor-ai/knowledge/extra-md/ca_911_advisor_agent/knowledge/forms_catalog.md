## Core CPE funding forms

| Form | Purpose | Common pitfalls |
|------|---------|-----------------|
| **Advance Notification for CPE Funding** | Signals intent; starts Branch budgeting/eligibility workflow | Submitted too early/late; missing PSAP identity; no eligibility date context |
| **CPE Fixed Allotment / Pre-authorization letter** | Official $ eligibility communication | Treating calculator estimate as this letter |
| **CPE Statement of Work (SOW)** | Vendor deliverables, schedule, configuration | Missing acceptance testing; network impact omitted; wrong model mix |
| **Price quote / cost workbook** | Itemized pricing vs MPA max | Tax/maint not split; residual lines mixed into base without clarity |
| **TDe-285 CPE Allotment Spending Plan** | How allotment (and residual plan) will be used | GIS lines mixed incorrectly; incomplete residual plan |
| **TD-288 Commitment to Fund** | Authorizes funded amount/items; tracking # | PSAP authorizes vendor **before** TD-288; invoice missing tracking # |
| **TD-284 System Acceptance** | Certifies accepted system; payment + residual clocks | Not routed to Branch; ETS not updated; acceptance date unclear |
| **TD-290 / TD-290A** | Reimbursement claim (+ wages support) | Missing TD-288, proof of payment, travel policy, or support docs |

## Package completeness quick matrix

For **direct** path purchase approval readiness, expect:

1. Adv Notice history on file  
2. Allotment letter amount referenced (do not invent)  
3. Advisor-reviewed SOW  
4. Matching price quote  
5. Spending plan (TDe-285 or current)  
6. Current procurement instrument (per Branch procedure)  
7. Ship-to = install site; bill-to = Branch for funded lines (direct)  
8. MPA compliance statement with contract number when on MPA  

See `playbooks/PB04_td288_package.md`.

## Invoice hygiene (post TD-288)

- TD-288 tracking number on vendor invoice  
- Account naming convention from TD-288  
- Breakdown: equipment, labor, taxes, surcharges as required  
- Direct path: contractor → Branch after acceptance rules

## Agent behavior

- Name the form; explain why it is needed now  
- Do not fill official signature blocks as if you were the Branch  
- Offer draft field checklists, not forged completed legal instruments
