# Glossary (agent-critical)

Working definitions for the Co-Pilot. Expand with `source_extracts/Acronym Sheet.md` and Operations Manual Glossary PDFs when needed. Prefer plain language in answers; use acronyms after first expand.

---

## Funding and SETNA

| Term | Meaning |
|------|---------|
| **SETNA** | State Emergency Telephone Number Account; surcharge-funded account supporting statewide 9-1-1 programs |
| **Warren Act** | Warren 911 Emergency Assistance Act (Gov. Code ~53100–53120); authority frame for California 9-1-1 system |
| **CA 9-1-1 Branch** | Cal OES Public Safety Communications unit overseeing standards, funding, and compliance support |
| **PSAP** | Public Safety Answering Point; primary answers 9-1-1 directly; secondary receives transfers |
| **CPE** | Customer Premises Equipment; call-handling system (on-prem or cloud) |
| **Fixed allotment** | CPE funding eligibility amount from Branch methodology (call volume driven) |
| **Allotment letter** | Official Branch communication of CPE fixed allotment / pre-authorization |
| **Advance Notification (AN)** | Form signaling PSAP intent to use CPE funds; budgeting/process start |
| **Residual** | Allotment remaining after complete system cost; restricted to approved list |
| **Direct funding** | Contractor invoices Branch after TD-288 / acceptance rules |
| **Reimbursement** | PSAP pays then claims via TD-290 |
| **MPA** | Master Purchase Agreement for 9-1-1 CPE contractors |
| **CMAS** | California Multiple Award Schedule path (where applicable) |
| **Lab-validated** | Vendor/system validated in CA 9-1-1 Branch lab for funded use |
| **ATA** | Annual Training Allotment; separate from CPE residual |
| **GIS allotment** | Separate funding pot for GIS; do not casually mix with CPE residual |

## Forms (common)

| Term | Meaning |
|------|---------|
| **TD-288 / TDe-288 / PSC-288** | Commitment to Fund; tracking number on invoices |
| **TD-284** | System Acceptance and Authorization; residual clocks; payment path |
| **TDe-285** | CPE Allotment Spending Plan |
| **TD-290 / TD-290A** | Reimbursement claim / wage support document |
| **TD-280 family** | New PSAP / plan / connectivity related forms |

## Operations and data

| Term | Meaning |
|------|---------|
| **ECaTS** | MIS/call accounting used for volume and answer-time analytics |
| **ETS** | Branch Emergency Telephone Systems database (equipment/billing tracking) |
| **FOR** | Fiscal and Operational Review |
| **MSAG** | Master Street Address Guide |
| **ANI / ALI** | Automatic Number / Location Identification |
| **ASA** | Average Speed of Answer |
| **SOW** | Statement of Work |
| **FI$Cal** | State financial/procurement system path |
| **County Coordinator** | County-designated role for MSAG/coordination; often reimbursed for approved tasks |
| **NG9-1-1 / i3** | Next Generation 9-1-1 / NENA i3 architecture |
| **RNSP / PNSP** | Regional / Prime network service provider roles (NG network context) |
| **Host-remote** | Shared CPE host with remote positions (agreement-driven) |

## Performance

| Term | Meaning |
|------|---------|
| **Answer-time standard** | Training/Manual language: at least 90% of 9-1-1 calls answered within 15 seconds |
| **TTY / TDD** | Text telephone capability for accessibility |

## Usage rule

When a user uses a term ambiguously (e.g. “allotment” vs “TD-288”), clarify which document they mean before giving dollar or approval advice.
