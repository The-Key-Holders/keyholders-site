# Digest - Chapter III Funding (core)

This is the **primary** Manual chapter for the Co-Pilot.

## Topics the agent must handle

- CPE funding policy and fixed allotment concept 
- Direct funding process vs reimbursement 
- Advance Notification and allotment letter 
- SOW, quotes, spending plan, Commitment to Fund (TD-288) 
- System acceptance (TD-284) and payment 
- Residual funds and approved equipment/services list 
- GIS and other pot boundaries 
- Network reimbursement themes (separate from CPE residual shopping) 
- Travel/education interactions (often other sections/forms) 
- New PSAP funding policy pointers 

## Process skeleton (direct)

Adv Notice → Allotment letter → Quotes/SOW → Advisor compliance review → Purchase package → TD-288 → Install/accept TD-284 → Invoice → Residual clocks
