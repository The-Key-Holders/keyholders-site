## Two paths

| Path | When | Who pays vendor first |
|------|------|------------------------|
| **Direct (MPA)** | Lab-validated MPA (or allowed CMAS) procurement; Branch direct pay model | Contractor invoices **Branch** after TD-288 + acceptance rules |
| **Reimbursement** | Local procurement / PSAP pays | PSAP pays → **TD-290** claim with required attachments |

MPA is not always mandatory, but enables direct funding and MPA max-price shopping.

---

## Direct path steps (coach this)

| Step | Actor | Action | Timing notes |
|------|-------|--------|--------------|
| 1 | PSAP | Submit **Advance Notification for CPE Funding** | Typically no more than ~1 year before eligibility/need; eligibility often 5 years from last TD-284 |
| 2 | Branch | Issue **CPE Fixed Allotment letter** | Process extracts cite ~3 weeks (newer) or older ~8 weeks pre-auth; use current practice |
| 3 | PSAP | Shop **lab-validated** vendors; obtain quotes | MPA prices are **maximums** |
| 4 | Contractor | Prepare **SOW + price quote** | Align to MPA terms |
| 5 | Advisor | **Compliance review** of SOW/quote | Target ~2 weeks feedback if deficient |
| 6 | Advisor + PSAP | **Purchase approval package** | SOW, quote, spending plan, current requisition/FI$Cal path |
| 7 | Branch | Issue **TD-288** | PSAP should not authorize vendor spend before this |
| 8 | PSAP + Vendor | Install; **acceptance testing** | Per contract |
| 9 | PSAP | Submit **TD-284** | Payment path + residual clocks start |
| 10 | Contractor | Invoice Branch | TD-288 # + naming convention |
| 11 | PSAP + Advisor | Residual (if any) | Approved list; ~90-day quotes; ~12-month invoice/claim |

**Coordination:** moves/replacements affecting network include network provider(s) and Advisor early.

## Reimbursement path notes

1. Pre-approval / TD-288 still matters for funded equipment classes. 
2. TD-290 package: claim form + TD-288 + invoices + proof of payment (and travel policy for travel-type claims). 
3. Incomplete packages return with dispute notification pattern (training reimbursement policy). 
4. Educational materials / CALNENA / CPE-GIS reimburse classes differ in attachments; classify first.

---

## CPE vs network vs GIS (do not mix casually)

| Track | What it funds |
|-------|----------------|
| **CPE allotment** | Call-handling system and related CPE policy items |
| **Network / NG9-1-1** | Call delivery path, ESInet/provider services (separate contracts) |
| **GIS allotment / plan** | GIS services/software/equipment per GIS rules |
| **ATA** | Training; separate from CPE residual |

---

## Eligibility and maintenance themes

- Full replacement cycle: generally **5 years from system acceptance (TD-284)** 
- Years **6–7:** extended maintenance may be fundable with **pre-approval** (confirm current Manual) 
- Year **8+:** maintenance often PSAP cost; escalate edge cases 
- Cloud may have different extended maint commercial pattern; refresh still relevant for residual opportunity 

---

## Advisor value moments

1. Catch bad SOW/quote **before** package assembly 
2. Keep residual plan **during** replacement, not as afterthought 
3. Enforce TD-288 before vendor authorization 
4. Start residual clocks on TD-284 
5. Keep CPE vs network answers clean on live calls
