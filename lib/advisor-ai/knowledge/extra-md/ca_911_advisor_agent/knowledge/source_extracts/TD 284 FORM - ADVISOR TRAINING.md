*TD 284 FORM / SYSTEM ACCEPTANCE FORM*

* RECEIVE TD284 FORM / “SYSTEM ACCEPTANCE FORM” FROM AGENCY
  + VENDORS CAN OBTAIN A COPY OF THIS FROM THE CA 9-1-1 WEBSITE
    - [*http://www.caloes.ca.gov/cal-oes-divisions/public-safety-communications/ca-9-1-1-emergency-communications-branch/ca-9-1-1-forms*](http://www.caloes.ca.gov/cal-oes-divisions/public-safety-communications/ca-9-1-1-emergency-communications-branch/ca-9-1-1-forms)
* PRINT OUT A COPY
  + MAKE AN ADDITIONAL COPY OF THE SIGNATURE PAGE AND ROUTE TO UNIT SUPERVISOR
* PUT LAST PAGE, SIGNATURE PAGE, IN FRONT THE PLACE ON TOP OF CPE TD288 IN RED FOLDER FOR QUICK VIEWING OF SYSTEM ACCEPTANCE DATE.
* PLACE EMAIL THAT THE TD284 CAME WITH IN PSAP EMAIL FOLDER. IF TD284 IS MAILED, SCAN AND PLACE EMAIL IN PSAP EMAIL FOLDER.
  + PLACE COPY OF TD284 IN SHARED DRIVE
* OPEN CA 9-1-1 DATABASE PROGRAM
  + PULL UP PSAP
  + GO TO PSAP CPE SECTION
  + CLICK “EDIT PSAP” BUTTON
  + CHANGE ALL FIELDS PSAP CPE INFORMATION
  + USE TD288 AND TD284 CHANGE VENDOR, EQUIP TYPE, MONTHLY COST, 5 YR TOTAL COST, DATE APPROVED, NUMBER OF POSITIONS FUNDED.
    - (NOTE ON POSITIONS; PSAPS CAN BUY MORE POSITIONS IF NEEDED, WE INPUT INTO FIELD THE NUMBER OF BY POLICY WE FUND FOR THIS PSAP. BUT IF PSAP BOUGHT MORE POSITIONS THAN FUNDED, THEN ENTER A NOTE IN THE COMMENTS SECTION.
* SYSTEM INSTALL DATE..LEAVE BLANK.
* *SYSTEM ACCEPTANCE DATE FROM TD284 5/15/2017*
* BILLING START DATE, ENTER AS EXACTLY (1) YEAR FROM SYS ACCEPT DATE
