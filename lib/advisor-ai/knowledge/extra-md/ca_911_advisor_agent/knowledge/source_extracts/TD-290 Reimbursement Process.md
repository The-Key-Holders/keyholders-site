Reimbursements for CPE equipment, GIS equipment and services, and residual funds items should arrive at the 9-1-1 Consultant’s Desks

Reimbursements for Annual Training Allotment, County Coordinators, PSAP Meetings, educational materials, and special projects should go directly to Deirdre.

For reimbursements that you are to review here is the process:

1. Ensure the TD-290 is complete,
   1. contact and accounts payable information is present,
   2. appropriate boxes are checked for Type,
   3. description is included,
   4. all items/TK numbers/amounts are listed,
   5. and financial official section is complete with signature.
2. Ensure that the correct paperwork is attached
   1. Copy of our signed TD-288 (we can use our original if they forget and we can match it up accurately)
   2. Copy of the vendor invoice(s)
   3. Copy of agency’s check(s) showing payment amounts and dates
3. Verify that the amount claimed on the TD-290 does not exceed the amount approved on the TD-288
   1. Check the amount claimed against the original TD-288, the actual invoiced amount, and the amount paid by the agency
   2. If amount requested is correct, note the correct amounts again in the CA 9-1-1 Branch Use Only column for each item as well as the total
   3. If amount requested exceeds the TD-288 amount approved:
      1. Determine why this is, and if it is due to taxes/shipping/etc consult your supervisor
      2. If the excess amount in unfounded, note the lower approved amount in CA 9-1-1 Branch Use Only column
         1. Note the corrected amount for each line item as applicable
         2. Note the corrected Claim Total Amount
4. Sign the TD-290
   1. Include the PSAP Code, Date, Fiscal Year, and Object Code
5. Send to supervisor for approval in a colored folder
6. When returned to you, give to Deirdre for processing (and keep a copy of the 290 in your file as a placeholder)
7. When Deirdre completes processing and returns it to you:
   1. File in the RED CPE or Green/Blue GIS folder if applicable
   2. File in the White binder if no colored folder is present
