# 13 · Funding Eligibility by Project Type

**Aid type:** Matrix · **Priority:** Additional · **Use:** Quick “what pot of money?” reference

> **Policy of record:** Live CA 9-1-1 Operations Manual, current forms, and allotment matrices on [caloes.ca.gov/911](https://www.caloes.ca.gov/911) supersede this aid if they differ. Use as an internal Advisor quick-reference only.

| Project / need | Typical funding track | Primary vehicle / forms | Notes |
|----------------|----------------------|-------------------------|-------|
| Full CPE replacement / certified upgrade | **CPE Fixed Allotment** | Adv Notice, allotment letter, TDe-285, TD-288, TD-284 | 5-year cycle |
| Residual items after CPE | **CPE residual** | Same project + residual list | Timing windows apply |
| Extended CPE maint Y6–7 | **CPE maint (special)** | Pre-approval | Not from next allotment (confirm) |
| CPE repair (damage) | **Case-by-case** | Request + justification | Negligence → PSAP |
| GIS data/systems | **GIS allotment** | GIS process / TD-288 | LOA may be required |
| Network circuits / NG services | **Network funding** | Network orders / MSA | Separate from CPE |
| Annual training / courses | **ATA** | Pre-approval + TD-290 | Not CPE residual |
| County Coordinator activities | **Coordinator track** | Pre-approval + reimb | Special routing |
| New PSAP startup | **New PSAP policy** | TDe-280 + criteria | Strict eligibility |
| Educational materials / meetings | **Agency 9-1-1 expenses** | Pre-approval | Reimb admin path often |
| Language interpretation | **State contract** | Usage reports | FOR review item |

## Rule of thumb
If it is **not** call-handling CPE in the PSAP work area on the **CPE residual list**, it is **probably not** CPE residual—find the correct track.
