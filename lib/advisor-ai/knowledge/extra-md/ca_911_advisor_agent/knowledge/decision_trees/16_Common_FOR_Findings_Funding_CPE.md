## Common funding / CPE findings & Advisor prep

| Finding theme | What it looks like | Advisor prep / coaching |
|---------------|--------------------|-------------------------|
| Cycle timing confusion | PSAP thinks they are eligible early / late | Bring TD-284 date + cycle chart (Aid 08) |
| Missing Advanced Notification | Project surprise mid-year | Explain budget cycle (Aid 14); set cohort outreach |
| Residual misunderstanding | Expect furniture/network from residual incorrectly | Residual tree + approved list (Aid 09) |
| CPE vs network mix-up | Network costs charged against CPE thinking | Aid 02 comparison in FOR Section II/III |
| Incomplete TD-288 / invoice trail | Footprint ledger gaps | Reconcile red folder before FOR |
| Extended maint without approval | Year 6–7 invoices unexpected | Pre-approval rule; 2-month lead time |
| Answer-time risk | Ops performance drives political heat | ECaTS 12-month ASA; Chapter I standard |
| Cloud / NG unreadiness | Legacy CPE blocking migration | Section V discussion + demos |
| ATA unused or misrouted | Training funds left on table or wrong form path | ATA process reminder |
| ECaTS / MIS gaps | Data missing for allotment or performance | Connectivity check; funding risk |

## FOR meeting tip
Lead with **Summary findings**, then deep-dive only red items. Leave PSAP with **written next actions** and form names.
