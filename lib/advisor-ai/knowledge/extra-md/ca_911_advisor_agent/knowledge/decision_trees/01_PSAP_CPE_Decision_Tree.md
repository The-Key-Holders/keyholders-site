# 01 · PSAP CPE Decision Tree — New Contract Transition

**Aid type:** Decision tree · **Priority:** Highest · **Use:** Live calls during 2026–2027 transition

> **Policy of record:** Live CA 9-1-1 Operations Manual, current forms, and allotment matrices on [caloes.ca.gov/911](https://www.caloes.ca.gov/911) supersede this aid if they differ. Use as an internal Advisor quick-reference only.

## When to use
PSAP asks about replacing CPE, new MPA contract, Cloud vs on-prem, eligibility timing, or “what do we do next?”

## Fast diagnosis path

```
START: What is the PSAP’s primary question?
│
├─ A. “Are we eligible for CPE replacement funding?”
│     → Check: years since last TD-284 system acceptance
│        · < 5 years → Not yet eligible for full replacement cycle (unless certified upgrade path)
│        · = 5 years (month 60) → Eligible for refresh / Advanced Notification window
│        · Years 6–7 → Extended maintenance may be fundable (pre-approval); refresh still recommended
│        · Year 8+ → Maintenance generally PSAP responsibility; escalate for case review
│
├─ B. “How much is our allotment?”
│     → Run Fixed Allotment calc (ECaTS call volume → funding level → positions → MPA estimate)
│     → Issue Fixed Allotment / pre-authorization letter after valid Advanced Notification
│     → Remind: official allotment is set by Branch; calculator is estimation support only
│
├─ C. “Cloud or on-premise?”
│     → Both may be available under current/new MPA; lab-validated vendors only
│     → Cloud: NENA i3 / NG9-1-1 friendly; month-to-month extended maint after 60 months typical
│     → On-prem: traditional backroom; refresh still needed for residual window
│     → Share comparison table (Aid 10); encourage demos
│
├─ D. “CPE contract vs network / NG9-1-1 contract?”
│     → Different contracts, scopes, and funding tracks — see Aid 02
│     → CPE = call-handling equipment in PSAP / cloud call handling
│     → Network = RNSP/PNSP, ESInets, routing — separate from CPE allotment
│
├─ E. “What forms / steps?”
│     → Advanced Notification → Allotment letter → Quotes/SOW → Advisor review
│       → Purchase approval package → TD-288 → Install/accept (TD-284) → Invoice / residuals
│     → Full flowchart: Aid 04
│
├─ F. “Can we use leftover / residual money?”
│     → Residual = allotment minus cost of complete system replacement
│     → Must be on approved residual list; request with/during replacement
│     → Quotes/POs typically within 90 days of acceptance; invoice/TD-290 timelines apply
│     → Residual decision tree: Aid 09
│
├─ G. “Equipment damaged / needs repair?”
│     → Negligence / inadequate facility → PSAP responsibility
│     → Act of nature + reasonable protection → case-by-case Branch review
│     → Damage decision tree: Aid 15
│
└─ H. “Training / ATA / other funding?”
      → Separate from CPE allotment (ATA, GIS, network, agency expenses)
      → Eligibility matrix: Aid 13
```

## Advisor talk track (30 seconds)
1. Confirm **last acceptance date** and whether they are in year 5–7 of the cycle.  
2. Separate **CPE equipment** questions from **NG9-1-1 network** questions.  
3. Point to **Advanced Notification** if they need funding in the next fiscal year.  
4. Offer **MPA quote comparison** and **Cloud demos** when selecting systems.  
5. Capture action: form needed, calc needed, or escalate to supervisor.

## Key forms (quick)
| Form | Role |
|------|------|
| Advanced Notification for CPE Funding | Budget signal; starts eligibility process |
| CPE Fixed Allotment / Pre-authorization letter | States approved allotment amount |
| TDe-285 Spending Plan | Plans full allotment + residual use |
| TD-288 Commitment to Fund | Authorizes spend |
| TD-284 System Acceptance | Enables payment / residual clock |
| TD-290 Reimbursement Claim | When PSAP paid vendor (reimb path) |
