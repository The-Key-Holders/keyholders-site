# 15 · “My CPE is Damaged / Needs Repair” Decision Tree

**Aid type:** Decision tree · **Priority:** Additional · **Use:** Damage vs replacement guidance

> **Policy of record:** Live CA 9-1-1 Operations Manual, current forms, and allotment matrices on [caloes.ca.gov/911](https://www.caloes.ca.gov/911) supersede this aid if they differ. Use as an internal Advisor quick-reference only.

## Policy basis (Chapter III)
PSAPs must provide adequate facility conditions (HVAC, power, protection).  
- Damage from **negligence or inadequate facilities** → **PSAP responsibility**  
- Damage from **act of nature** (or similar) where PSAP made **reasonable effort to protect** → Branch **may** fund replacement parts/repairs **case-by-case**

## Decision tree

```
1. Is the system still under warranty / active maintenance agreement?
   YES → Open ticket with CPE vendor first (maintenance may cover).
   NO / unclear → continue with Branch path

2. What caused the damage?
   A. PSAP negligence / poor environment (power, HVAC, liquid, mishandling)
      → PSAP funds repair/replace; document for file
   B. Act of nature / external event + reasonable protection efforts
      → Gather photos, incident reports, insurance notes → case-by-case Branch review
   C. Manufacturer defect / install issue under contract
      → Vendor/warranty path; Advisor supports

3. Is a full refresh already eligible (year ≥5)?
   YES → Consider folding into replacement project vs piecemeal repair
   NO → Repair path if approved; do not invent early full-allotment replacement

4. Documentation packet for Branch review (when seeking funding)
   - Incident narrative & date/time
   - Photos / police or facilities reports if any
   - Vendor diagnosis & quote
   - Proof of reasonable protection / maintenance environment
   - Insurance determination if applicable
```
