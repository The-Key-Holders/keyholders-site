# 18 · Three-System Model (Database + Network + CPE)

**Aid type:** Visual · **Priority:** Additional · **Use:** Explain how the ecosystem connects

> **Policy of record:** Live CA 9-1-1 Operations Manual, current forms, and allotment matrices on [caloes.ca.gov/911](https://www.caloes.ca.gov/911) supersede this aid if they differ. Use as an internal Advisor quick-reference only.

## Model
```
[Caller] → [NETWORK / NG9-1-1] → [CPE Call Handling] → [Telecommunicator]
                ↑                         ↑
         Location / routing          CAD / GIS / Logging / Radio interfaces
                ↑
         [DATABASE / GIS / ALI services]
```

| Layer | Function | Funding typically |
|-------|----------|-------------------|
| **Database / location** | ALI, GIS data quality, location accuracy services | GIS allotment / network-related services (context-dependent) |
| **Network** | Deliver call & data to correct PSAP (ESInet, RNSP/PNSP) | Network contracts |
| **CPE** | Present call to telecommunicator; text; IRR; interfaces | CPE fixed allotment |

## Why Advisors draw this on whiteboards
PSAPs often assume “9-1-1 system” is one contract. Showing three layers prevents residual/network mix-ups and sets up NG migration conversations.
