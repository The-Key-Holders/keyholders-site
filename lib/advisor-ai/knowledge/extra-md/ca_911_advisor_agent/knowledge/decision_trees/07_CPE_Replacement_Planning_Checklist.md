# 07 · CPE Replacement Planning Checklist for PSAPs

**Aid type:** Checklist · **Priority:** Supporting · **Use:** Guide PSAPs through full process

> **Policy of record:** Live CA 9-1-1 Operations Manual, current forms, and allotment matrices on [caloes.ca.gov/911](https://www.caloes.ca.gov/911) supersede this aid if they differ. Use as an internal Advisor quick-reference only.

## Phase 0 — Readiness (Advisor + PSAP)
- [ ] Confirm **last TD-284 acceptance date** and cycle year  
- [ ] Confirm **ECaTS** connection healthy  
- [ ] Identify **Cloud vs on-prem** interest; schedule demos if needed  
- [ ] Flag **network/NG9-1-1** dependencies / cutover risks  
- [ ] Review open **residuals**, prior TD-288s, folder status  

## Phase 1 — Funding notice
- [ ] Complete **Advanced Notification for CPE Funding**  
- [ ] Submit within Branch timing guidance (≈ ≤1 year before need / eligibility)  
- [ ] Receive **Fixed Allotment / pre-authorization letter**  
- [ ] File letter in PSAP CPE project (red) folder  

## Phase 2 — System selection
- [ ] Obtain **multiple MPA quotes** (lab-validated vendors only for direct path)  
- [ ] Compare identical/similar configurations for best value  
- [ ] Contractor prepares **SOW + itemized price quote**  
- [ ] Advisor completes **compliance review**  

## Phase 3 — Approval package
- [ ] Finalize MPA-compliant SOW/quote  
- [ ] Complete **TDe-285 CPE Allotment Spending Plan** (include residual plan)  
- [ ] Complete current **purchase approval / requisition / FI$CAL** steps with Advisor  
- [ ] Receive **TD-288 Commitment to Fund**  
- [ ] PSAP authorizes contractor **only after** TD-288 (direct path)  

## Phase 4 — Install & accept
- [ ] Coordinate install schedule with **network provider** if impacted  
- [ ] Complete **acceptance testing** per contract  
- [ ] Submit signed **TD-284**  
- [ ] Vendor invoices Branch with **TD-288 tracking #** (direct path)  

## Phase 5 — Residuals & closeout
- [ ] Residual quotes/POs within **90 days** of acceptance (confirm current rule)  
- [ ] Only **approved residual list** items  
- [ ] Invoice / TD-290 within required window  
- [ ] Advisor updates ETS; archive red folder when complete
