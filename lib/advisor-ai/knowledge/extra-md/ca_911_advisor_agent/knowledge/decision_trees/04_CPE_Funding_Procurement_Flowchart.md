# 04 · CPE Funding & Procurement Process Flowchart

**Aid type:** Flowchart · **Priority:** Highest · **Use:** Core daily process from Advanced Notification to acceptance

> **Policy of record:** Live CA 9-1-1 Operations Manual, current forms, and allotment matrices on [caloes.ca.gov/911](https://www.caloes.ca.gov/911) supersede this aid if they differ. Use as an internal Advisor quick-reference only.

## Direct funding path (MPA) — modern Branch process

| Step | Who | Action | Timing notes (policy / practice) |
|------|-----|--------|-----------------------------------|
| 1 | PSAP | Submit **Advanced Notification for CPE Funding** | No more than ~1 year before eligibility (5 years from acceptance); supports Branch budgeting |
| 2 | Branch | Issue **CPE Fixed Allotment / pre-authorization letter** | Practice target often within ~3 weeks of complete notice (older docs cited ~8 weeks — use current practice) |
| 3 | PSAP | Obtain **MPA quotes** from lab-validated vendors; compare features | MPA prices = maximums; shop multiple offers |
| 4 | Contractor | Prepare **SOW + price quote** | Must match MPA terms |
| 5 | Advisor | Review SOW/quote for **contract compliance** | Target feedback within ~2 weeks if deficient |
| 6 | Advisor + PSAP | Build **purchase approval package** | Includes compliant SOW/quote; internal requisition / FI$CAL process per current Branch procedure |
| 7 | Branch | Issue **TD-288 Commitment to Fund** | To PSAP and vendor when package is complete |
| 8 | PSAP + Vendor | Install; perform **acceptance testing** | Per contract |
| 9 | PSAP | Submit signed **TD-284 System Acceptance** | Enables payment |
| 10 | Contractor | **Invoice Branch** with TD-288 tracking # and account naming convention | Direct pay path |
| 11 | PSAP + Advisor | **Residual** quotes/POs (if any) | Typically within **90 days** of acceptance; approved residual list only |

## Reimbursement path (local procurement)
PSAP pays contractor → submits **TD-290** with TD-288, invoices, and proof of payment → Advisor verifies amounts ≤ approved → supervisor → fiscal processing. See Aid 11.

## Coordination note
Moves/replacements affecting network: include network provider(s) early.
