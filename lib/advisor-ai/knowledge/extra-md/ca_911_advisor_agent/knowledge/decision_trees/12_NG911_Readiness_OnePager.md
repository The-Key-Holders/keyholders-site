# 12 · NG9-1-1 Readiness — What PSAPs Need to Know

**Aid type:** One-pager · **Priority:** Supporting · **Use:** Explain why CPE decisions matter for network migration

> **Policy of record:** Live CA 9-1-1 Operations Manual, current forms, and allotment matrices on [caloes.ca.gov/911](https://www.caloes.ca.gov/911) supersede this aid if they differ. Use as an internal Advisor quick-reference only.

## Why CPE choice matters for NG9-1-1
The **network** delivers modern call/data types; the **CPE** must be able to **receive and process** them (voice, text, location, multimedia roadmaps). Selecting non-NG-capable CPE can force expensive interim workarounds or early replacement.

## PSAP readiness checklist
- [ ] Understand **separate** network vs CPE contracts (Aid 02)  
- [ ] Know regional **NG deployment status** (dashboard / provider updates)  
- [ ] Select **lab-validated**, NG-capable / **i3-friendly** CPE  
- [ ] Plan **cutover** with Advisor + CPE vendor + network provider  
- [ ] Confirm workstation, headset, logging, CAD/GIS interfaces still work end-to-end  
- [ ] Train staff on any new call-handling UI / text workflows  
- [ ] Align CPE refresh year with migration wave when possible  

## Advisor talking points
1. NG9-1-1 is not “just a phone company project”—**CPE must match**.  
2. Cloud CPE options exist specifically to ease NG transition—but **verify** current approved list.  
3. Funding for network ≠ automatic increase to CPE allotment.  
4. FOR meetings include **NG + Cloud CPE** discussion section—use them.
