# 02 · CPE Contract vs NG9-1-1 Network Contract

**Aid type:** Comparison chart · **Priority:** Highest · **Use:** Clarify frequent PSAP confusion

> **Policy of record:** Live CA 9-1-1 Operations Manual, current forms, and allotment matrices on [caloes.ca.gov/911](https://www.caloes.ca.gov/911) supersede this aid if they differ. Use as an internal Advisor quick-reference only.

## One-sentence distinction
**CPE** is the **call-handling system** the telecommunicator uses to answer 9-1-1.  
**Network** is the **path that delivers** the call (and NG9-1-1 services) to that system.

## Side-by-side

| Topic | CPE (Customer Premise Equipment) | NG9-1-1 / Network Services |
|-------|----------------------------------|----------------------------|
| What it is | Call-handling workstations, controllers/servers or cloud call handling, IRR, UPS, interfaces used to answer 9-1-1 | ESInet / RNSP / PNSP, routing, ALI/location services, trunking/connectivity to the PSAP |
| Where it “lives” | On-premise equipment room **or** cloud/data-center call handling | Provider network infrastructure + PSAP edge connectivity |
| Primary contract vehicle | **CPE Master Purchase Agreement (MPA)** (or local procurement + reimbursement) | **Network / NG9-1-1 service agreements** (separate from CPE MPA) |
| Funding source track | **CPE Fixed Allotment** (call-volume based) + residuals | **Network services funding policy** (separate process) |
| Typical forms | Advanced Notification, allotment letter, TDe-285, TD-288, TD-284, TD-290 | Network orders / network-specific pre-approval (not the CPE allotment forms) |
| Refresh cycle | **~5-year** CPE cycle from system acceptance | Network migration milestones set by Branch / providers (not the same as CPE year-5) |
| Vendor selection | Lab-validated CPE vendors on MPA (e.g. historically Cloud: Atos, Lumen, NGA 911 — verify current list) | Network service providers under State NG9-1-1 contracts |
| Advisor role | Allotment calc, SOW/quote compliance, residual eligibility, acceptance | Coordinate cutovers affecting CPE; clarify billing; do not merge network costs into CPE allotment without policy basis |
| Common PSAP mix-up | “Our network upgrade uses our CPE money” | **Usually false** — different pots unless Branch explicitly directs otherwise |

## Talk track
> “Your **CPE allotment** pays for the system your call-takers use to answer 9-1-1. Your **network / NG9-1-1 contract** pays for how calls get to that system. Changing one does not automatically fund the other — but they **must be coordinated** so cutovers don’t drop 9-1-1.”

## Coordination rule
Any CPE move/replacement that **impacts network services** must involve: PSAP manager, Advisor, CPE contractor, and network provider(s).
