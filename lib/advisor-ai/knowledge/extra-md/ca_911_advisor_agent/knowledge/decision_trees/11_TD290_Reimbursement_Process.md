# 11 · Reimbursement Claim Process (TD-290)

**Aid type:** Flowchart · **Priority:** Supporting · **Use:** Claims review path

> **Policy of record:** Live CA 9-1-1 Operations Manual, current forms, and allotment matrices on [caloes.ca.gov/911](https://www.caloes.ca.gov/911) supersede this aid if they differ. Use as an internal Advisor quick-reference only.

## When TD-290 applies
PSAP (or agency) **paid the vendor** and seeks reimbursement for pre-approved items (CPE residual items, GIS, training, etc. depending on claim type).

## Advisor review steps (CPE / GIS / residual claims)

1. **Completeness of TD-290**
   - Contact & accounts payable info  
   - Type boxes checked  
   - Description present  
   - Items / TK numbers / amounts listed  
   - Financial official signature complete  

2. **Attachments**
   - Signed **TD-288** (match from file if PSAP omits)  
   - Vendor **invoice(s)**  
   - Agency **check(s)** / proof of payment with amounts & dates  

3. **Amount verification**
   - Claim ≤ **TD-288** approved amount  
   - Align claimed, invoiced, and paid amounts  
   - If over: investigate taxes/shipping with supervisor; note corrected amounts in Branch Use Only column  

4. **Sign & route**
   - Sign; enter PSAP Code, Date, Fiscal Year, Object Code  
   - Supervisor approval (colored folder practice)  
   - Fiscal processing (historically routed to reimbursement admin for certain claim types)  
   - File copy in **red CPE** or **green/blue GIS** folder as applicable  

## Routing split (historical desk practice — confirm current)
| Claim type | Typical first desk |
|------------|--------------------|
| CPE / GIS / residual reimbursements | Assigned Advisor review |
| ATA, County Coordinators, PSAP meetings, educational materials, special projects | Reimbursement administrator path |
