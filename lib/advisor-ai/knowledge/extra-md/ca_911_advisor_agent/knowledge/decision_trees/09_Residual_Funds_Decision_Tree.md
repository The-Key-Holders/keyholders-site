# 09 · Residual Funds — Can We Use Them?

**Aid type:** Decision tree · **Priority:** Supporting · **Use:** Purchase / residual questions

> **Policy of record:** Live CA 9-1-1 Operations Manual, current forms, and allotment matrices on [caloes.ca.gov/911](https://www.caloes.ca.gov/911) supersede this aid if they differ. Use as an internal Advisor quick-reference only.

## Definition
**Residual funds** = CPE fixed allotment eligibility **minus** final cost of the **complete** 9-1-1 system replacement (or certified upgrade).

## Decision tree

```
1. Is this during / after a complete CPE replacement or certified upgrade?
   NO  → Residual program does not apply. Route to other funding type (Aid 13).
   YES → continue

2. Is there allotment remaining after the complete system cost?
   NO  → No residual. Project is at/over allotment (review quotes / scope).
   YES → continue

3. Is the item on the current Branch Residual / Incremental Approval List
   AND used in the 9-1-1 call-taking work area / equipment room in direct
   support of delivering 9-1-1 to the call-taker?
   NO  → Deny residual use (or escalate rare exceptions per supervisor).
   YES → continue

4. Was residual use planned / requested with the project (TDe-285 spending plan)
   and quotes/POs submitted within required window (commonly 90 days after acceptance)?
   NO  → Late — escalate; do not promise funding.
   YES → continue

5. Will invoice / TD-290 (if reimbursement) be completed within required timeline
   (e.g., within 12 months of acceptance per residual doc — confirm current)?
   NO  → Risk of loss of residual — escalate immediately.
   YES → Process TD-288 for residual items; track on footprint ledger.
```

## Common residual-eligible categories (verify live list)
Additional positions · mapping monitors · GIS items · logging recorder · headsets · workstation furniture (scoped) · chairs (limits) · PMP/ENP consulting · temporary relocation · pre-arrival systems · certain backroom/cloud items · UPS upgrades, etc.

## Hard no / caution examples
- Items **not** in direct support of 9-1-1 call delivery  
- Unscoped office furniture / storage beyond policy  
- Using residual for **network** circuit costs without explicit policy  
- Spending residual **before** understanding complete system cost
