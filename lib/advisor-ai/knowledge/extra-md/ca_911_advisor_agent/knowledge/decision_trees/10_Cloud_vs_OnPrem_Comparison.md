# 10 · Cloud vs On-Premise CPE (New Contract)

**Aid type:** Comparison table · **Priority:** Supporting · **Use:** Help PSAPs choose

> **Policy of record:** Live CA 9-1-1 Operations Manual, current forms, and allotment matrices on [caloes.ca.gov/911](https://www.caloes.ca.gov/911) supersede this aid if they differ. Use as an internal Advisor quick-reference only.

## Comparison

| Dimension | Cloud / Data-center CPE | On-premise CPE |
|-----------|-------------------------|----------------|
| Primary location of call-handling core | Provider cloud / data center | PSAP equipment room |
| NG9-1-1 / NENA i3 alignment | Generally designed for NG/i3 workflows | Varies by product generation; confirm lab validation |
| Local hardware footprint | Reduced backroom; edge devices still required | Full controllers/servers/UPS backroom |
| Facility dependencies | Still need power, networking, workstations, headsets, etc. | Higher dependence on HVAC, power, space for servers |
| Maintenance after 60 months | Often month-to-month until refresh (confirm contract) | Extended maint years 6–7 options per policy |
| Refresh / residual opportunity | Refresh still recommended at cycle to update + residuals | Same 5-year cycle logic |
| Procurement | Lab-validated MPA vendors only for State-funded path | Same MPA expectation for direct funding |
| Vendor demos | Strongly encourage multi-vendor demos | Same |
| Advisor messaging | Neutral facilitator; no brand preference | Neutral facilitator |

## Historical Cloud vendor note (verify current list)
Prior Branch correspondence referenced approved cloud call-handling sellers such as **Atos, Lumen, and NGA 911**. **Always verify the current validated vendor list** on the Branch contracts page before advising.

## Decision prompts for PSAPs
1. Facility constraints (space, power, HVAC)?  
2. Timeline relative to **NG9-1-1 cutover**?  
3. Staff comfort with cloud operations / vendor SLAs?  
4. Total cost of ownership within **allotment** (incl. 5-year package)?  
5. Continuity / failover design requirements?
