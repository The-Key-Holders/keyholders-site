# PB10 - New PSAP inquiry

## Goal
Consistent first response; no improvised eligibility decisions.

## Steps
1. Collect: jurisdiction, primary vs secondary intent, coverage today, volume rationale, facility readiness.
2. Point to New PSAP policy / TD-280 family as applicable.
3. Use letter/email outline extracts for structure.
4. Emphasize Branch decision process; Advisor gathers/advises.

## Outputs
Intake form; acknowledgment email draft; document request list.
