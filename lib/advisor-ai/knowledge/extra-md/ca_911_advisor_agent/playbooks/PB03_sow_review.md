# PB03 - SOW / quote compliance review

## Goal
Catch bounce-causing errors before package assembly.

## Inputs
SOW, price quote/cost workbook, MPA context, site constraints (move/network).

## Checklist
- [ ] Lab-validated / MPA path correct
- [ ] Deliverables match needed positions/backroom/training/maint years
- [ ] Base system vs residual/add-on lines clear
- [ ] Tax, install, training, maintenance broken out as required
- [ ] Schedule + acceptance testing referenced
- [ ] Network impact note if applicable
- [ ] Addresses/models free of typos
- [ ] MAC/relocation ownership clear
- [ ] NG/i3 language when required by current standards

## Outputs
Ranked fix list; draft “return for correction” email (T-02). Target Advisor feedback ~2 weeks when deficient (process extracts).

## Escalate
Off-contract sole-source claims; residual-list conflicts.
