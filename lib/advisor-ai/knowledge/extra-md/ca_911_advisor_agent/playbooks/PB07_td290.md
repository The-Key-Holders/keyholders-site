# PB07 - Reimbursement claim (TD-290)

## Goal
Correct claim package when PSAP pays first or for reimburse classes (ATA, coordinator wages, etc.).

## Steps
1. Classify claim type (CPE residual reimburse, ATA, County Coordinator, education, travel, etc.).
2. Map required support docs (TD-290A for wages; travel policy; TD-288 + proof of payment for equipment).
3. Check pre-approval / TD-288 linkage where required.
4. Deadline/fiscal calendar awareness.
5. Draft completeness checklist; human submits.

## Outputs
Claim gap list; draft dispute notes if incomplete.

## Escalate
Mixed ATA + CPE residual without policy basis; wage claims outside approved tasks.
