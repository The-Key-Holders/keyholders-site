# PB09 - Answer-time / compliance outreach

## Goal
Performance conversation with consistent tone.

## Steps
1. State standard: ≥90% answered within 15 seconds.
2. Present last ~12 months trend **from real data**.
3. Collaborative improvement themes (staffing, flow, tech) without overclaiming local constraints.
4. Use low-answer-time script structure for live calls.
5. Draft follow-up email; human decides formal letter.

## Outputs
Talk track; draft email; optional improvement plan outline.
