# PB05 - Residual funds and clocks

## Goal
Spend residual correctly and on time.

## Steps
1. Confirm residual $ = allotment − complete system (if positive).
2. Confirm TD-284 acceptance date → compute ~90-day and ~12-month targets.
3. Check each item against **current residual list version**.
4. Enforce 9-1-1 workspace / direct 9-1-1 traffic support rule.
5. Draft residual request checklist and email (T-05/T-06).

## Outputs
Residual clock block; item membership results; next actions.

## Escalate
Off-list items, post-deadline requests, damage framed as residual.
