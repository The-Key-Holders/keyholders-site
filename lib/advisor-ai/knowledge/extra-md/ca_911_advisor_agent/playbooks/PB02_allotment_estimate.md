# PB02 - Allotment estimate (not official)

## Goal
Order-of-magnitude funding understanding via fixed allotment methodology.

## Inputs
- ECaTS Call Summary and/or Top Busiest Hours
- Or manual monthly stats
- Cloud vs on-prem mode if relevant
- Price pack version if dollarizing

## Steps
1. Prefer CPE Fixed Allotment Calculator (PortablePost / Excel / web peer).
2. Validate ECaTS layout (vertical vs horizontal).
3. Run estimate; record assumptions and variance controls.
4. Present **ESTIMATE ONLY** block per RESPONSE_FORMAT.
5. Official amount = Branch allotment letter after valid Adv Notice.

## Outputs
Estimate summary, assumptions log, “what changes official $” list.

## Never
Issue TD-288 numbers; invent volumes.
